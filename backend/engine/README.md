# TradePilot discovery modules

Upload `influencer.py` and `web_discovery.py` into `backend/engine/`.

They use public RSS/Atom feeds and keep source URLs with each signal.
They do not invent influencer data or bypass private logins.

Optional Render variable:
`TRADEPILOT_INFLUENCER_FEEDS=https://example.com/feed.xml,https://example.org/rss`
